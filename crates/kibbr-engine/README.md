# kibbr-engine is discontinued

This crate was the engine of [kibbr](https://crates.io/crates/kibbr), a database for
structured JSON logs. From kibbr 0.5.0 the engine is part of the `kibbr` crate, and this
crate gets no more releases.

- To run kibbr: `cargo install --locked kibbr`
- Source and issues: https://github.com/pratyaydeep/kibbr
- This crate never promised a stable API. Earlier versions stay available for the kibbr
  releases that depend on them.
